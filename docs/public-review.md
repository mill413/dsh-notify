# 公开仓库准备审查

审查日期：2026-10-23。范围为当前工作树、所有本地 Git refs 可达的历史、源码依赖、文档、旧 CI 和 npm 打包内容。

## 结论

可以作为开源源码仓库公开。本次检查没有发现必须阻止公开的凭据泄漏或外部 harness 源码依赖；这不是完整安全审计或生产运行认证。正式发布新版本前，建议处理下方的前端遗留问题并完成真实浏览器验收。

本轮未创建 GitHub 仓库、提交或推送代码、发布 npm、安装插件或重启服务。已有的 `0.2.1-rc.3` SDK 升级工作树改动已保留。

## 已修复

- **接口地址校验**：原来只检查 `http(s)://` 前缀，现在解析 URL 并校验协议、主机；拒绝 fetch 不支持的 URL 内嵌用户名和密码。
- **模板变量解析**：原来 `{{constructor}}`、`{{toString}}` 等可能读取对象原型属性。现在仅允许读取模板变量对象的自身属性，未知变量保持原样。
- **测试草稿的空字段**：原来清空 URL、正文或图标后测试，会静默使用已保存值。现在明确传入的空字符串被保留；空 URL 会报错，空正文与图标按草稿处理。解析函数移入可独立测试的 HTTP 模块。
- **共享依赖声明**：补齐 React 及代码引用的宿主 SDK peers，保留 npm 精确版本开发依赖及明确兼容范围。
- **开发与文档**：固定 pnpm 版本，声明 Node 要求；重写 README，补充实际触发差异、安装、配置、隐私、超时、浏览器限制及独立验证方法。旧升级说明标记为历史记录。
- **旧 Gitea CI**：移除网络探测和写死的内网地址，改用 `GITEA_BASE_URL` 仓库变量；检出凭据通过临时 Git 配置传递，避免写入 remote URL；从 npm pack 的 JSON 输出读取本次产物，避免误选旧 tarball。
- **忽略规则**：增加环境文件、日志、覆盖率和 dist 目录的忽略规则。

## 剩余问题

### 中：前后端默认请求体不一致

`src/client/prefs.ts` 的 `DEFAULT_BODY_TEMPLATE` 缺少宿主 `src/push.ts` 默认模板中的 `icon`。正常读取设置后会使用宿主值，但客户端回退配置与服务端定义仍不一致。客户端注释也错误地声称空图标字段会被删除；实际会保留空字符串。

建议统一默认值并补回归测试，然后在真实 DSH 中验证首次打开设置、编辑、保存和图标测试推送。

### 中：设置卡片尚未完全符合宿主组件规范

`src/client/NotifySettingsCard.tsx` 中图标 URL 使用原生 `<input>`，但 `.dsn-input` 仅设置布局，没有原生 Input 的完整尺寸、边框和状态；方法使用 `<select>`，按钮亦有自定义实现。文本域与选择框使用 border-l4，而工作区规范要求与 Models 页 border-l2 对齐。

建议改用宿主公开的 Input、Button、Menu 等组件，按需使用 portal，并验证浅色／深色、键盘 focus、减少动画、展开／收起／保存。此次没有修改前端运行代码，也没有进行浏览器验收；不能据此宣称界面已符合全部规范。

### 低：Git 历史保留旧 CI 内网地址

当前文件已清理，但两个历史版本仍含旧内网地址。它们不是认证凭据。公开完整历史时这些地址和提交作者元数据仍会公开；此次没有重写历史。

### 发布流程尚未启用

没有 `.github/workflows` 和 npm Trusted Publisher 配置。旧 Gitea 流程依赖新增仓库变量，尚未在远端执行。下一阶段应单独配置 GitHub CI、公开包元数据和 npm 发布，并验证 tag 与版本匹配。
